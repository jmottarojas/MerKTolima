# Directorio de Medios - Merktolima

Este directorio contiene los archivos de medios subidos por los usuarios.

## Estructura

- `products/` - Imágenes de productos subidas por los vendedores

## Configuración

- Tamaño máximo de archivo: 5MB
- Formatos soportados: JPG, PNG, GIF
- Los archivos se renombran automáticamente con UUID para evitar conflictos

## Seguridad

- Solo se permiten archivos de imagen
- Validación de tipo MIME
- Validación de tamaño de archivo
- Nombres de archivo únicos generados automáticamente
